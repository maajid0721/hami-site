# HAMI Tech Labs website

A simple, responsive corporate profile website for HAMI Tech Labs.

## Homepage
- Introduces HAMI Tech Labs as the parent technology venture.
- Briefly presents HAMI App and HAMI FIT as products being developed under HAMI Tech Labs.
- Includes the company's approach, location and general contact address.
- Keeps product-specific details, app-store links, pricing and detailed policy pages out of the current homepage.

## Main files
- `index.html` — corporate homepage
- `styles.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/favicon.svg` — site icon
- `CNAME` — existing custom-domain file (preserve unchanged)

## Release notes
This repository's feature branch is used for preview work. Do not merge to `main`, change DNS, or publish to the production domain without explicit approval.

The current website is an informational corporate profile. Product pages, app-store links, product screenshots, pricing and product-specific policy information can be added after HAMI App and HAMI FIT are publicly launched.
