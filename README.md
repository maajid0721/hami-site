# HAMI website

A responsive static landing page for HAMI.

## Files
- `index.html` — content and SEO metadata
- `styles.css` — responsive styling
- `script.js` — mobile navigation and footer year
- `assets/favicon.svg` — site icon
- `CNAME` — custom domain for GitHub Pages

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
3. Confirm the custom domain `hamiapp.in` and configure the DNS records recommended by GitHub Pages.
4. Preserve existing MX, SPF, DKIM and DMARC records used by email.
5. Enable **Enforce HTTPS** after GitHub Pages issues the certificate.

The page describes HAMI's document organisation, manual expense tracking, reminders and AI assistance at a high level. It avoids unverified security certifications or encryption promises.
